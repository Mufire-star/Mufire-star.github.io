K1 RVV 加速 & SNN-STDP FPGA 实现总结

一、K1 RVV 双电机同步监测系统

项目路径：D:\Projects\K1_RVV

面向 MUSE Pi K1（SpacemiT K1 RISC-V 处理器）的双电机同步监测工程。

当前实现

  • C 语言音频分析核心，使用 RVV 向量扩展加速热点计算
  • CLI 分析入口：支持离线 WAV 文件和 ALSA 实时音频
  • scalar / rvv 对照 benchmark：对比标量和向量化加速效果
  • Python 网页服务：K1 端运行，浏览器可查看实时数据
  • 完整基础链路：上板运行 + 浏览器查看 + 公开数据演示

项目结构

K1_RVV/
├── benchmarks/     # scalar / rvv 对照测试
├── build/          # 编译产物
├── configs/        # 配置文件
├── data/           # 测试数据
├── docs/           # 项目文档 + 演示指南
└── k1_web/         # 浏览器查看页面

待完成

  • STM32 控制闭环
  • MA-USB8 真实波束控制
  • 全通道麦克风独立频谱展示

二、K1 AI Agent

项目路径：D:\Projects\K1_ai_agent

K1 板上的 AI 代理项目，包含 agent 调度逻辑和 SSH 远程管理功能，在 MUSE Pi K1 上运行轻量级 AI 任务。

三、SNN-STDP 脉冲神经网络 FPGA 实现

项目路径：D:\Projects\SNN-STDP

在 ZCU104 上实现基于 STDP（Spike-Timing-Dependent Plasticity） 学习规则的脉冲神经网络硬件加速。

当前状态

  • Vitis HLS 综合已进行，部分模块通过综合
  • 板级测试已进行 DFX Runtime Profile：CPU 0:0:1 / WALL 0:0:0
  • 生成测试数据：board_scores_current82.json（82 个样本的评估分数）
  • 权重文件：board_stdp_weights_last.npz

技术细节

  • 使用 Vitis HLS 进行 C++ 到 RTL 的综合
  • STDP 学习规则硬件化，支持片上在线学习
  • 与 GCNN-DVS 项目共享 ZCU104 硬件平台
  • PYNQ 框架用于 PS-PL 通信和结果读取
