博客开篇

2026-05-24 随笔 #杂谈

这是我的个人博客第一篇文章 (ฅ^u u^ฅ)

之前一直在用 GitHub 仓库直接记录各种学习笔记和项目文档，但总觉得缺少一个系统化整理的地方。很多时候东西写完了就忘记了放在哪个角落，或者是学过之后忘记了下次要用还要重新学或者东西要重新找，回头翻找起来非常麻烦。

于是就有了这个博客。

为什么搞这个博客？

主要几个原因：

  1. 做自己的知识库 —— 把学过的东西写成文章是最好的复习方式，也能帮自己理清思路（一生一芯等）
  2. 记录项目进展 —— FPGA 相关项目等，方便自己回顾和复盘(大概率懒得写)
  3. 分享交流 —— 希望能和有兴趣的朋友一起讨论和交流，互相学习成长

博客会写什么？

内容大概会集中在以下几个方向：

  • 学习记录 —— 主要记录自己的学习心得和记录
  • 开发工具 —— Vivado、Vitis、Git、等工具的配置和使用
  • 随笔反思 —— 阶段性的学习和生活总结

关于这个站

本博客使用 GitHub Pages 搭建，所有代码在 Mufire-star 仓库中维护。如果你有什么建议或发现了错误，欢迎提 Issue 或 PR。

"The best way to learn is to teach." —— 写博客就是教自己。

好了，开篇就到这里。接下来会随缘更新相关笔记，敬请期待喵~
