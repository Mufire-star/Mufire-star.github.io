一、聚合 AI (juhe-ai)：OpenAI API 中转与账号管理系统

44|

项目路径：D:\Projects\juhe-ai

45|

轻量级 OpenAI 兼容中转、账号调度与 API Key 管理系统。适合个人、小团队把多个 OpenAI 上游账号集中管理。

46| 47|

核心功能

48|
    49|
  • 统一入口：对外暴露一个 /v1 端点，客户端只需填写 Base URL 和本地 API Key
    • 50|
  • 多账号调度：支持 OpenAI OAuth 和 API Key 两种账号，后台管理启停、优先级、并发、代理
    • 51|
  • 分组授权：分组绑定上游账号，API Key 绑定分组，不同业务隔离使用
    • 52|
  • 自动故障切换：账号限流或异常时自动切换到同组其他账号
    • 53|
  • 用量统计：记录请求、模型、Token、耗时、成本估算，31 天趋势
    • 54|
  • 性能监控：首 token / 总耗时平均值和最大值趋势
    • 55|
56| 57|

技术栈

58|
    59|
  • 前端：Vue 3 + TypeScript + Ant Design Vue（中文界面）
    • 60|
  • 后端：Node.js + TypeScript
    • 61|
  • 存储：SQLite（无需 Redis / PostgreSQL）
    • 62|

二、AiWorkspace：多角色 AI 协作工作台

67|

项目路径：D:\Projects\Ai_Workspace

68|

本地可运行的多角色 AI 工作台，浏览器中与统一入口对话，内部由 Front / Worker / Reviewer 三个角色协作执行。

69| 70|

功能特点

71|
    72|
  • 浏览器聊天入口
    • 73|
  • 三角色协作闭环：Front（前端交互）→ Worker（执行任务）→ Reviewer（审查结果）
    • 74|
  • 实时角色状态展示、任务流转展示、活动日志展示
    • 75|
  • 最终结果展示
    • 76|
  • 历史会话 + 运行历史持久化保存
    • 77|
  • 每次运行生成结构化产物文件
    • 78|
79| 80|

技术栈

81|
    82|
  • Python（纯后端，app.py 约 3000 行）
    • 83|
  • 内置 HTTP 服务器 + 浏览器前端
    • 84|
  • 支持 PowerShell 一键启动（aiworkspace.ps1）
    • 85|

三、DeepSeek-TUI：Rust 实现的 DeepSeek 终端编码 Agent

90|

项目路径：D:\Projects\DeepSeek-TUI

91|

Terminal coding agent for DeepSeek V4。从 deepseek 命令启动，流式显示推理过程，支持本地工作区编辑和自动模式。

92| 93|

项目结构

94| 
DeepSeek-TUI/
    95|├── crates/
    96|│   ├── agent/          # Agent 核心逻辑
    97|│   ├── app-server/     # 应用服务器
    98|│   ├── cli/            # 命令行入口
    99|│   ├── config/         # 配置管理
   100|│   ├── core/           # 核心抽象
   101|│   ├── execpolicy/     # 执行策略
   102|│   ├── hooks/          # 钩子系统
   103|│   ├── mcp/            # Model Context Protocol
   104|│   ├── protocol/       # 协议定义
   105|│   ├── secrets/        # 密钥管理
   106|│   ├── state/          # 状态管理
   107|│   ├── tools/          # 工具集
   108|│   ├── tui/            # TUI 界面
   109|│   └── tui-core/       # TUI 核心组件
   110|├── Cargo.toml          # Rust workspace 配置
   111|└── README.md
112| 113|

技术特点

114|
    115|
  • 纯 Rust 实现，14 个 crate 的 workspace 架构
    • 116|
  • 流式推理块显示（reasoning blocks）
    • 117|
  • 本地工作区编辑 + 审批门（approval gates）
    • 118|
  • 自动模式：每轮自动选择模型和思考级别
    • 119|
  • 支持 npm / cargo 两种安装方式
    • 120|
