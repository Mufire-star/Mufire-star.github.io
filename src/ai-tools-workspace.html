一、聚合 AI (juhe-ai)：OpenAI API 中转与账号管理系统

44| 44| 44|

项目路径：D:\Projects\juhe-ai

45| 45| 45|

轻量级 OpenAI 兼容中转、账号调度与 API Key 管理系统。适合个人、小团队把多个 OpenAI 上游账号集中管理。

46| 46| 46| 47| 47| 47|

核心功能

48| 48| 48|
    49| 49| 49|
  • 统一入口：对外暴露一个 /v1 端点，客户端只需填写 Base URL 和本地 API Key
    • 50| 50| 50|
  • 多账号调度：支持 OpenAI OAuth 和 API Key 两种账号，后台管理启停、优先级、并发、代理
    • 51| 51| 51|
  • 分组授权：分组绑定上游账号，API Key 绑定分组，不同业务隔离使用
    • 52| 52| 52|
  • 自动故障切换：账号限流或异常时自动切换到同组其他账号
    • 53| 53| 53|
  • 用量统计：记录请求、模型、Token、耗时、成本估算，31 天趋势
    • 54| 54| 54|
  • 性能监控：首 token / 总耗时平均值和最大值趋势
    • 55| 55| 55|
56| 56| 56| 57| 57| 57|

技术栈

    59| 59| 59|
  • 前端：Vue 3 + TypeScript + Ant Design Vue（中文界面）
    • 60| 60| 60|
  • 后端：Node.js + TypeScript
    • 61| 61| 61|
  • 存储：SQLite（无需 Redis / PostgreSQL）
