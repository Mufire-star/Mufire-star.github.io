FPT'26 项目进展记录

截至 5 月 14 日，FPT'26 Track A 的完整工作流已经完成。

已完成的工作

  • 6 阶段 Agent 工作流：需求解析 → 代码生成 → RAG 增强 → 编译验证 → 反馈循环 → 性能评估
  • DeepSeek API 提供商集成，通过本地代理 127.0.0.1:7897 访问
  • RAG 模式库：7 种 HLS 加速模式
  • 反馈循环机制：自动读取编译错误并修正代码
  • IEEE 论文草稿，包含实验数据对比表
  • SVG 工作流架构图
  • RAG 消融实验数据

待解决的问题

  • sqrtf() 不是编译期常量，导致时序恶化 —— 需要提示 LLM 使用 HLS 数学库
  • RAG 检索不够精确，有时检索到不相关的模式
  • DeepSeek API 偶尔超时，需要重试机制

下一步

  • 优化提示词模板，强制 LLM 使用 HLS 友好的数学函数
  • 改进 RAG 向量检索的相似度阈值
  • 完善论文草稿中的数据分析和讨论部分
