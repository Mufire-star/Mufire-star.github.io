项目概述

45|

FPT'26 Design Competition Track A —— LLM4HLS Agent。目标是构建一个基于大语言模型的智能 Agent，能够自动生成 Vitis HLS 兼容的 C/C++ 代码，辅助 FPGA 高层次综合流程。

46|

合作者：ForBloodB（Co-author）

47| 48|

技术架构

49|

完整的 6 阶段 Agent 工作流：

50|
    51|
  1. 需求解析 —— 将自然语言描述转换成结构化规范
    2. 52|
  2. 代码生成 —— DeepSeek API 生成 Vitis HLS 兼容 C++ 代码
    3. 53|
  3. RAG 增强 —— 基于 7 种 HLS 加速模式库进行检索增强
    4. 54|
  4. 编译验证 —— 自动调用 Vitis HLS 综合与仿真
    5. 55|
  5. 反馈循环 —— 根据编译错误自动修正代码（3 轮迭代）
    6. 56|
  6. 性能评估 —— 对比生成 RTL 与手写 RTL
    7. 57|
