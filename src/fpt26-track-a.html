FPT'26 Track A：LLM4HLS Agent —— 用大语言模型辅助高层次综合

项目地址：github.com/Mufire-star/FPT

项目概述

FPT'26 Design Competition Track A —— LLM4HLS Agent。目标是构建一个基于大语言模型的智能 Agent，能够自动生成 Vitis HLS 兼容的 C/C++ 代码，辅助 FPGA 高层次综合流程。

合作者：ForBloodB（Co-author）

技术架构

完整的 6 阶段 Agent 工作流：

  1. 需求解析 —— 将自然语言描述转换成结构化规范
  2. 代码生成 —— DeepSeek API 生成 Vitis HLS 兼容 C++ 代码
  3. RAG 增强 —— 基于 7 种 HLS 加速模式库进行检索增强
  4. 编译验证 —— 自动调用 Vitis HLS 综合与仿真
  5. 反馈循环 —— 根据编译错误自动修正代码（3 轮迭代）
  6. 性能评估 —— 对比生成 RTL 与手写 RTL

关键技术细节

  • DeepSeek API：通过本地代理 127.0.0.1:7897 访问
  • RAG 模式库：Pipeline、Array Partition、Dataflow、Loop Unroll、Function Inline、Interface Synthesis、Memory Reorg
  • 反馈循环：3 轮迭代，每次读取 csynth.xml 解析时序/资源数据
  • Token 效率指标：定义 E = latency_improvement / total_tokens
