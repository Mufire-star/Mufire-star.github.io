Vivado / Vitis 2025.2 使用小记

Windows 11 下配置 Vitis HLS 2025.2 的一些踩坑记录 (ฅ^u u^ฅ)

环境配置

  • Vivado / Vitis 2025.2 安装在 D:\Programs\Xilinx\2025.2
  • Git Bash 使用 D:\Programs\Git\bin\bash.exe，而非 WSL
  • Teχ Live 2026 在 D:\Programs\texlive\2026

必须设置 HERMES_GIT_BASH_PATH

在 Hermes Agent 中运行 Vitis HLS 时，必须设置环境变量：

export HERMES_GIT_BASH_PATH="D:/Programs/Git/bin/bash.exe"

这会强制使用 Git Bash 而不是 WSL，避免 WSLInterop 禁用导致的路径解析问题。

常见错误

1. WSL 启动 banner 污染文件内容

当使用 Hermes 的 write_file 工具时，如果终端通过 WSL 连接，文件会被 WSL 启动 banner 的 UTF-16 null 字节污染。解决方法：通过 Git Bash 写入，或使用 Python 脚本写入。

2. Vitis HLS 路径空格问题

默认安装路径 C:\Program Files\Xilinx 有空格。建议安装到 D:\Programs\Xilinx 避免引号转义问题。

3. Git for Windows 的路径分隔符

Git Bash 中应使用正斜杠 / 替代反斜杠 \。例如：D:/Programs/Xilinx/2025.2/Vivado/bin/vivado

推荐配置

在 ~/.bashrc 中加入：

# Vitis/Vivado
export XILINX_HLS="D:/Programs/Xilinx/2025.2/Vitis_HLS"
export PATH="$XILINX_HLS/bin:$PATH"

# Git Bash override
export HERMES_GIT_BASH_PATH="D:/Programs/Git/bin/bash.exe"
