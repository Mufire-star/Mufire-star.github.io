一、CNN-DVS：红外图像 Tiny YOLO 目标检测

项目路径：D:\Projects\cnn_dvs

在红外图像流上训练一个小型 YOLO 类 CNN。只使用 udp 红外图像流（忽略 combine 和 usb 图像）。

数据集结构

dataset/
├── train/.../udp/0.png
├── val/.../udp/0.png
├── test/.../udp/0.png
└── label/0.txt  (YOLO 格式)

实验配置

  • 对比实验配置（YAML）：fused vs half precision、udp3 vs usb1 数据源
  • 消融实验：dataset_udp_highacc.yaml、dataset_udp_map50_finetune.yaml
  • 融合 YOLO 实验：fused_yolo.yaml
  • 半精度训练对比：sbalanced_fused_half_r1.yaml

二、CNN-FINN：Xilinx FINN 框架探索

项目路径：D:\Projects\cnn_finn

Xilinx FINN 框架的本地部署和实验。FINN 是一个用于在 FPGA 上部署量化神经网络的框架，支持从训练到部署的端到端流程。

  • 包含 FINN 官方仓库的全部源码（finn/ 子目录）
  • Docker 构建脚本（run-docker.sh）
  • 自定义 HLS 组件（custom_hls/）
  • FINN 运行时库（finn-rtllib/）

三、RISC-V CPU 设计

项目路径：D:\Projects\riscv_cpu_design

一个简单的单周期 RISC-V CPU，用 Verilog 实现，包含完整的指令集执行单元。

模块列表

  • PC：程序计数器
  • IM：指令存储器
  • IR：指令寄存器
  • RF：寄存器堆
  • ALU：算术逻辑单元
  • EXT：立即数扩展
  • DM：数据存储器
  • ControlUnit：控制单元
  • NPC：下一条 PC 计算
  • MUX_2to1/3to1：多路选择器
  • Flopr：寄存器（带复位）

包含 UVM 验证环境和波形仿真脚本。

四、KiCad 测试板设计

项目路径：D:\Projects\test_board

使用 KiCad 设计的 PCB 测试板，包含原理图和 PCB 布局。用于硬件调试和功能验证。

  • KiCad PCB 工程文件（test_board.kicad_pro / .kicad_pcb / .kicad_sch）
  • 多版本迭代（test_board_fixed / kicad10 / kicad6）
  • 备份文件（test_board-backups/）
